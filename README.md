# Coffeecionado Media Kit 2026

Media kit bilingue (PT/EN) do [@coffeecionado.pt](https://www.instagram.com/coffeecionado.pt/): estatísticas de Instagram, audiência, caso em destaque, formatos de colaboração e contactos.

**Online:** https://coffeecionadopt-stack.github.io/media-kit/
Link direto em inglês: https://coffeecionadopt-stack.github.io/media-kit/#en

## Estrutura

- `index.html` — a página toda (HTML, CSS e JS num só ficheiro)
- `assets/` — fotos, miniaturas dos reels e logo (versão clara e escura)

## Atualizar os números

Os números estão escritos diretamente no `index.html`, em duas versões por valor:
`<span class="pt">…</span>` (formato português, ex. `499 mil`) e `<span class="en">…</span>` (ex. `499K`).
Fonte atual: estatísticas do Instagram exportadas do Edits a 12/11/2026.
